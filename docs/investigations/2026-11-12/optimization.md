## Operational changes and limits

- **Cloud build policy:** routine CI still compiles/lints the Linux backend and builds changed frontend code. Platform installers and Docker images require manual opt-in. See [release instructions](../../RELEASE_GUIDE.md). Update branch-protection requirements to `Validate Linux` if old matrix check names were required; remote rules were not edited.
- **Manual releases:** install/signing/container builds and actual publication have not been exercised. Historical tags predating the new CI helpers fail early with a documented error. Native signature presence and artifact checksums are checked; this is not cryptographic verification of the signatures. Actionlint ran without optional shellcheck/pyflakes.
- **IP bindings:** admission reserves durable zero-usage bindings, including failed/cancelled requests. Response accounting alone increments usage. Bindings do not expire when a request finishes; administrators must manage bindings or replace the token. Auth-off attribution and primary/admin credentials retain their distinct behavior.
- **Listener changes:** restart the app/server process to rebind its persistent administration listener. Wildcards retain the existing dual-stack fallback. Specific non-loopback interfaces do not support the loopback-only internal warmup endpoints; that boundary was retained. Named tunnel origins must be updated separately in Cloudflare. See [listener configuration](../../HEADLESS_BINDING.md).
- **Media compatibility:** gateway-local file references now fail explicitly. Send their bytes from the client as a data URI or use remote storage. URL-bearing audio/video fields require HTTP(S) or data URIs; bare audio base64 belongs in `input_audio.data`. Text, tool definitions, arguments and arbitrary tool-result JSON are not interpreted as media references.
- **Platform coverage:** focused checks ran on Windows. Linux CI execution, macOS runtime, release installers, Google upstream calls and production load were not exercised locally. Automatic cross-platform packaging no longer provides incidental coverage of those paths.
- **Commit scope:** application, thinking-test maintenance, CI/CD and investigation records are committed separately. Commit references identify verified existing PRs for the affected implementations and review context; these follow-up fixes do not claim to merge those PRs anew. Contributor attribution in the earlier integration commits is preserved.
